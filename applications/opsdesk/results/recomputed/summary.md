# Recomputed OpsDesk verdicts (offline replay)

Every stored trace re-scored with the fixed detector (`detector.py`). No model was
re-run. Generated by `code/replay.py`; do not hand-edit.

`old` is the as-shipped rule (`checker_v0.py`) run on the *same file*, so the two
columns differ only by the detector fix.

Historical `findings.md` files carry a banner pointing here, except `sweep-01` and
`sweep-02`, whose directories are write-protected (`dr-xr-xr-x`) as the repository's
freeze convention -- their corrected counts are in the table below only.

**A violation is a property of the trace, not a verdict on the agent.** The `policy`
column records whether the requirement was stated to the agent at all: `L0` cells
never stated it, so an L0 violation is evidence of under-specification as much as of
agent behaviour. See `../../opsdesk/README.md` section 6.
