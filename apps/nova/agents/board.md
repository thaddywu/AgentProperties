# Executive Board (`board`)

Scripted principal. Creates trusted source assignments for Procurement, Facility and HR and sends each its rationale. Assignment ingestion is distinct from an ordinary message computed using previous receipts. Board also receives audit coverage receipts and reports completion when the configured three parts are covered.

Board is exempt from the three-part combination restriction, but still subject to capability requirements. Coverage receipts do not give Board the auditors' complete received knowledge. Board does not centrally approve each message.

Available tools: None. Behavior is implemented by the trusted assignment path, message runtime and audit-receipt protocol; there is no LLM system prompt.
