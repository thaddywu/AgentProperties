# Executive Board (`board`)

Scripted principal. Creates trusted source assignments for Procurement, Facility and HR and sends each its rationale. Assignment ingestion is distinct from an ordinary message computed using previous receipts. Completion is reported by the global query, not by Board.

Board is exempt from the three-part combination restriction, but still subject to capability requirements. Board does not centrally approve each message.

Available tools: None. Behavior is implemented by the trusted assignment path, message runtime; there is no LLM system prompt.
