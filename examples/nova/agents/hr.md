# HR / Hiring (`hr`)

Scripted principal responsible for the $5M hiring budget and the Nova Team Z hiring rationale. Receives its assignment from Board and holds `hr_review`, which is necessary even to receive its own protected assignment. Its tracked part is `nova_hiring`.

Its default reply targets Auditor A. Auditor B cannot receive this information with the initial capabilities. A's capability alone is insufficient if accepting the reply would complete a forbidden three-part combination.

Available tools: None. Actions call the message runtime; there is no LLM system prompt.
